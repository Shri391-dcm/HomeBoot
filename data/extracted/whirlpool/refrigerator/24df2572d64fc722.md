# F72 through F78 - Error Code - Commercial Dryer

## Possible Solutions

- Power unit down by turning off the circuit breaker(s) for 5 minutes.
- Power up the unit by turning on the circuit breaker(s).
- Start a time dry cycle.
- Monitor the dryer for one minute to ensure the error code does not reappear.
